ℹ️ About — إدارة الموظفين
📋 وصف الأداة

الهدف: نقطة إدارة مركزية لحسابات الموظفين المستخدَمة في كل أدوات EcomModa — إضافة، تعديل الاسم، إيقاف/تفعيل، مسح PIN، وحذف نهائي. أي تغيير هنا ينعكس فوراً على كل الأدوات لأنهم كلهم بيقروا من نفس جدول employees في D1 المشترك.

المستخدمون المستهدفون: الموظفون المصرّح لهم بإدارة الحسابات فقط (عمود is_admin = 1 في جدول employees). أي موظف نشط لكن is_admin = 0 يقدر يسجّل دخول في باقي الأدوات عادي، لكن هذه الأداة تحديداً هترفضه برسالة "هذا الحساب غير مصرّح له بالدخول على أداة إدارة الموظفين".

كيف تعمل — Workflow

  1. الموظف يسجّل دخول بالـ PIN بتاعه (زي أي أداة تانية).
  2. تبويب "الموظفون" — عرض/إضافة/تعديل/إيقاف/تفعيل/مسح PIN/حذف.
  3. تبويب "سجل الدخول والخروج" — عرض كل عمليات الدخول/الخروج من كل الأدوات (عبر D1 المشترك).
  4. تبويب "سجل الإجراءات الإدارية" — سجل تدقيق (audit) لكل إجراء إداري تم في هذه الأداة نفسها، مع اسم منفّذ الإجراء.

🔧 تشريح الكود

FEATURE MAP

  • §AUTH — Universal D1 Auth (check_employee / register_pin / verify_employee / log_logout / get_employees)
  • §ADMIN — إدارة الموظفين (list/add/update/disable/enable/reset_pin/delete) + get_access_log
  • §LOG-ENDPOINTS — get_logs / get_logs_count / get_logs_export (سجل الإجراءات الإدارية)

KEY VARIABLES

  • currentEmployee — { username, displayName } في الذاكرة فقط، بيُبعت كـ actor مع كل إجراء إداري للتدقيق
  • TOOL_NAME = 'employees_admin' — قيمة tool في جدول logs لهذه الأداة

NOTES

  • CORS صارم (ALLOWED_ORIGINS) — أداة كتابة/تعديل على بيانات حساسة.
  • WORKER_SECRET مطلوب على كل الـ endpoints من غير استثناء — حتى get_employees.
  • الدخول على هذه الأداة مقصور على is_admin = 1 — التحقق بيحصل في check_employee (تحذير مبكر قبل الـ PIN) وفي verify_employee (تحقق نهائي، 403 لو مش admin).
  • عمود is_admin محتاج ALTER TABLE يدوي في D1 — مش جزء من الـ Worker code (انظر SETUP.txt).
  • موظف مايقدرش يسحب صلاحية الإدارة من نفسه (حماية من قفل النفس بره الأداة).
